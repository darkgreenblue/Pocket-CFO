# CFO جیبی (Pocket CFO)

یک ربات تلگرامی شخصی برای ثبت روزمره‌ی هزینه‌ها — مثل یک مدیر مالی جیبی که هر روز
با او حرف می‌زنی. کافی است یک **ویس** بگیری یا یک **متن** بفرستی و بگویی چه خرجی
کرده‌ای؛ ربات از حرفت تراکنش‌ها را استخراج می‌کند، برای هر کدام یک «کارت تأیید»
می‌فرستد و بعد از تأیید تو، آن را در دیتابیس ثبت می‌کند.

## ایده‌ی اصلی
- **هر تراکنش = یک بار کارت کشیدن**، نه تک‌تک اقلام. اگر از سوپرمارکت چند چیز با یک
  پرداخت بخری، یک تراکنش است و اقلام به‌عنوان متادیتا ذخیره می‌شوند.
- **مبلغ و عنوان اجباری‌اند** و قبل از ثبت باید تأیید انسانی شوند (با قابلیت ویرایش).
- مبلغ همیشه با جداکننده‌ی هزارگان و واحد (تومان/ریال) نشان داده می‌شود تا از خطای
  صفرها جلوگیری شود.
- **تگ‌گذاری خودکار:** مدل از یک «بانک تگ» موجود نزدیک‌ترین تگ‌ها را انتخاب می‌کند؛
  کد به‌صورت قطعی اعتبارسنجی و تطبیق می‌کند و هر چیز ناشناخته به صف پیشنهاد می‌رود.
- **یادآوری شبانه‌ی هوشمند:** فقط تراکنش‌هایی که ناقص‌اند یا گفته‌ای بعداً کامل می‌کنی.

## معماری
```
bot/
  config.py            # بارگذاری .env
  main.py              # راه‌اندازی Application و JobQueue
  utils/money.py       # parse/format مبلغ، واحد تومان/ریال
  db/                  # schema.sql + repo.py (SQLite)
  llm/                 # client (زنجیره‌ی fallback) + extract + prompts
  services/            # transactions, tags (تطبیق), reports, reminders
  flows/draft_flow.py  # رندر کارت تأیید + state ویرایش
  handlers/            # commands, messages (ویس/متن), callbacks, keyboards
data/tags_seed.json    # بانک تگ سلسله‌مراتبی اولیه
tests/                 # تست‌های واحد money و tags
```

### زنجیره‌ی LLM (Fallback)
درخواست رونویسی+تحلیل ویس در **یک** کال به مدل زده می‌شود:
1. `google/gemini-2.5-flash` (تایم‌اوت ۱۵ ثانیه)
2. همان مدل، پس از ۵ ثانیه وقفه
3. `google/gemini-2.5-flash-lite`
4. در صورت شکست همه → پیام «سرویس‌های هوش مصنوعی پاسخگو نیستند…»

## راه‌اندازی
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # سپس مقادیر را پر کن
python -m bot.main
```

### پر کردن `.env`
- `TELEGRAM_BOT_TOKEN` را از [@BotFather](https://t.me/BotFather) بگیر.
- `OPENROUTER_API_KEY` را از [openrouter.ai/keys](https://openrouter.ai/keys) بگیر.
- `ALLOWED_USER_IDS` را با آی‌دی عددی تلگرام خودت پر کن (از [@userinfobot]). اگر
  خالی بماند ربات به همه پاسخ می‌دهد.

> فایل `.env` در `.gitignore` است و هیچ‌وقت به گیت push نمی‌شود. کلیدها را فقط
> یک‌بار اینجا می‌گذاری.

## دیپلوی روی سرور
استقرار خودکار با **Docker + GitHub Actions** روی یک VPS خارجی انجام می‌شود (ربات با
polling کار می‌کند، پس دامنه/HTTPS لازم نیست). راهنمای کامل و یک‌بارهٔ راه‌اندازی در
[`DEPLOY.md`](DEPLOY.md) است. خلاصه: داکر را روی سرور نصب کن، `.env` را روی سرور بساز،
سه Secret (`SSH_HOST`/`SSH_USER`/`SSH_KEY`) را در گیت‌هاب بگذار، و یک push بزن.

اجرای محلی با داکر:
```bash
cp .env.example .env   # پرش کن
docker compose up --build
```

## یادداشت فنی: ورودی صوتی از طریق OpenRouter
جمینای ذاتاً ورودی صوتی را پشتیبانی می‌کند، اما پشتیبانی OpenRouter از فرمت
`ogg/opus` تلگرام باید در عمل تست شود. لایه‌ی `bot/llm/client.py` انتزاعی است؛ در
صورت نیاز با تغییر `OPENROUTER_BASE_URL`/مدل به Google Gemini مستقیم سوییچ کن.
